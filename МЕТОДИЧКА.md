# Методичка: создание проекта DemoExamAnother с нуля

## 1. Что делает проект

Это настольное приложение на Python и Tkinter. Оно:

- показывает окно авторизации;
- проверяет логин и пароль через PostgreSQL;
- требует собрать картинку из четырёх фрагментов;
- блокирует пользователя после трёх неудачных попыток;
- открывает обычную страницу пользователя или панель администратора;
- позволяет администратору добавлять, изменять, разблокировать и удалять обычных пользователей.

Проект учебный. Пароли пользователей сейчас сравниваются как обычный текст, поэтому такой вариант нельзя использовать в настоящей системе без доработки.

## 2. Что установить

### Программы

1. **Python 3.11 или новее**: https://www.python.org/downloads/
2. **PostgreSQL**: https://www.postgresql.org/download/
3. **Visual Studio Code**: https://code.visualstudio.com/

Во время установки Python в Windows нужно включить пункт **Add Python to PATH**.

### Расширения VS Code

Обязательные:

- **Python** от Microsoft (`ms-python.python`);
- **Pylance** от Microsoft (`ms-python.vscode-pylance`).

Удобные, но необязательные:

- **SQLTools** и расширение-драйвер PostgreSQL для просмотра базы из VS Code;
- **GitLens**, если проект хранится в Git.

Для запуска самого приложения дополнительные расширения VS Code не требуются.

## 3. Создание проекта

Откройте PowerShell и выполните команды:

```powershell
mkdir ExamTkinter
cd ExamTkinter
code .
```

Создайте виртуальное окружение:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если PowerShell запрещает запуск скриптов, выполните один раз от имени текущего пользователя:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

После активации в начале строки терминала появится `(.venv)`.

## 4. Установка библиотек

Tkinter обычно входит в стандартную поставку Python для Windows. Отдельно устанавливаются только драйвер PostgreSQL и его бинарные зависимости:

```powershell
python -m pip install --upgrade pip
python -m pip install "psycopg[binary]"
```

Проверка установки:

```powershell
python -c "import tkinter, psycopg; print('OK')"
```

В VS Code выберите интерпретатор из `.venv` через команду **Python: Select Interpreter**.

## 5. Структура проекта

После подготовки структура должна выглядеть так:

```text
ExamTkinter/
├── .venv/                 виртуальное окружение, не загружается в Git
├── pictures/
│   ├── 1.png              первый фрагмент капчи
│   ├── 2.png              второй фрагмент капчи
│   ├── 3.png              третий фрагмент капчи
│   └── 4.png              четвёртый фрагмент капчи
├── main.py                исходный код приложения
├── database.sql           SQL-скрипт, который можно создать по разделу 6
└── .gitignore
```

Имена изображений должны быть именно `1.png`, `2.png`, `3.png`, `4.png`.

## 6. Создание базы данных

Откройте **SQL Shell (psql)** или pgAdmin и создайте базу:

```sql
CREATE DATABASE demoekz;
```

Подключитесь к базе `demoekz` и выполните следующий скрипт:

```sql
CREATE TABLE users (
    id_user SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password_hash TEXT NOT NULL,
    is_admin BOOLEAN NOT NULL DEFAULT FALSE,
    failed_attempts INTEGER NOT NULL DEFAULT 0,
    is_locked BOOLEAN NOT NULL DEFAULT FALSE
);

INSERT INTO users
    (username, password_hash, is_admin)
VALUES
    ('admin', 'admin', TRUE),
    ('student', '1234', FALSE);
```

В `psql` подключение к базе выполняется командой:

```sql
\c demoekz
```

Проверка таблицы:

```sql
SELECT * FROM users;
```

Для текущего проекта подключение находится в `main.py`:

```python
DB = 'postgresql://postgres:123@localhost:5432/demoekz'
```

Здесь:

- `postgres` — пользователь PostgreSQL;
- `123` — пароль пользователя PostgreSQL;
- `localhost` — база запущена на этом компьютере;
- `5432` — стандартный порт PostgreSQL;
- `demoekz` — имя базы.

Если при установке PostgreSQL был задан другой пароль, замените `123` в строке `DB` на настоящий пароль. Это пароль сервера базы, а не пароль пользователя приложения.

## 7. Запуск приложения

Из каталога проекта с активным виртуальным окружением выполните:

```powershell
python main.py
```

Для проверки можно использовать учётные данные из SQL-скрипта:

```text
Администратор: admin / admin
Пользователь:   student / 1234
```

Помимо правильного пароля нужно правильно собрать капчу: фрагмент `1` должен попасть в место `1`, фрагмент `2` — в место `2` и так далее.

## 8. Как писать проект по шагам

### Шаг 1. Импорты

```python
import tkinter as tk
from tkinter import ttk, messagebox
from pathlib import Path
import psycopg
```

- `tkinter` создаёт основное окно и обычные элементы интерфейса;
- `ttk` содержит более современные виджеты Tkinter;
- `messagebox` показывает предупреждения и ошибки;
- `Path` помогает находить папку с изображениями независимо от текущего каталога запуска;
- `psycopg` подключает Python к PostgreSQL.

### Шаг 2. Настройки и тексты

```python
DB = 'postgresql://postgres:123@localhost:5432/demoekz'
PIC = Path(__file__).parent / 'pictures'
```

`__file__` — путь к текущему файлу `main.py`. Поэтому приложение ищет картинки рядом с исходным кодом, а не в случайной текущей папке.

Константы `LOCKED` и `WRONG` содержат сообщения, которые используются в нескольких местах.

### Шаг 3. Универсальная функция работы с базой

```python
def db(query, values=(), read=False):
    with psycopg.connect(DB) as connection:
        result = connection.execute(query, values)
        return result.fetchall() if read else None
```

- `query` — SQL-запрос;
- `values` — значения для параметров `%s`;
- `read=False` означает запрос изменения данных;
- `read=True` возвращает строки результата;
- `with` автоматически закрывает соединение и фиксирует успешную транзакцию.

Пример чтения:

```python
rows = db(
    'SELECT username FROM users WHERE username=%s',
    (username,),
    read=True
)
```

Параметры нельзя склеивать со строкой SQL вручную. Использование `%s` защищает запрос от SQL-инъекций.

### Шаг 4. Базовый класс интерфейса `UI`

Класс `UI` содержит общие операции:

- `label()` создаёт подпись;
- `button()` создаёт кнопку;
- `fields()` создаёт несколько подписей и полей ввода;
- `buttons()` создаёт набор кнопок;
- `clear()` удаляет элементы текущего экрана.

Благодаря этим методам одинаковый код не приходится повторять на странице входа и на странице администратора.

Параметр `grid=False` в `fields()` выбирает способ размещения элементов:

- `pack` используется на странице входа;
- `grid` используется в форме администратора.

### Шаг 5. Класс приложения `App`

```python
class App(UI):
```

`App` наследуется от `UI`, поэтому получает все вспомогательные методы интерфейса.

В конструкторе:

```python
def __init__(self, root):
    super().__init__(root)
    self.login_page()
```

- `super().__init__(root)` настраивает главное окно;
- `login_page()` сразу показывает форму входа.

### Шаг 6. Страница входа

Метод `login_page()` сначала вызывает `clear()`, чтобы удалить предыдущий экран. Затем создаёт:

1. заголовок;
2. поля логина и пароля;
3. информационную надпись;
4. капчу;
5. кнопки «Войти» и «Сбросить».

```python
self.login_entry, self.password_entry = self.fields(
    box, [('Логин', ''), ('Пароль', '*')]
)
```

Символ `*` скрывает ввод пароля.

### Шаг 7. Капча

`make_captcha()` загружает четыре изображения:

```python
self.images = {
    i: tk.PhotoImage(file=PIC / f'{i}.png').subsample(8, 8)
    for i in range(1, 5)
}
```

`subsample(8, 8)` уменьшает изображения в восемь раз.

`self.selected` хранит выбранный фрагмент, а `self.placed` — уже размещённые части. Обработчики событий делают следующее:

- `<Button-1>` выбирает фрагмент;
- `<ButtonRelease-1>` определяет место, куда его отпустили;
- `put()` помещает фрагмент в слот;
- `reset()` возвращает капчу в начальное состояние.

Условие успешной капчи находится в `login()`:

```python
all(self.placed.get(i) == i for i in range(1, 5))
```

Оно проверяет, что каждый фрагмент стоит на своём месте.

### Шаг 8. Авторизация

Метод `login()` выполняет последовательность:

1. получает логин и пароль из полей;
2. проверяет, что поля не пустые;
3. ищет пользователя в таблице `users`;
4. проверяет блокировку;
5. проверяет капчу и пароль;
6. увеличивает счётчик ошибочных попыток;
7. блокирует пользователя после трёх ошибок;
8. открывает страницу администратора или обычного пользователя.

Обработка ошибки базы:

```python
try:
    rows = db(...)
except psycopg.Error as error:
    messagebox.showerror('Ошибка базы данных', str(error))
```

Если пользователь ввёл неправильные данные, запрос обновляет поля:

```sql
UPDATE users
SET failed_attempts=%s, is_locked=%s
WHERE username=%s
```

### Шаг 9. Страницы пользователя и администратора

`user_page()` показывает сообщение об успешном входе и кнопку выхода.

`admin_page()` создаёт:

- форму добавления и редактирования пользователя;
- таблицу `ttk.Treeview`;
- кнопки изменения, разблокировки, удаления и выхода.

Метод `load()` заново загружает пользователей из базы и отображает их роль и статус.

Метод `selected_id()` возвращает идентификатор выбранной строки таблицы.

Методы администратора:

- `edit()` загружает данные выбранного пользователя в форму;
- `save()` добавляет нового пользователя или изменяет существующего;
- `clear_form()` очищает форму;
- `unlock()` сбрасывает блокировку и счётчик ошибок;
- `delete()` удаляет только пользователя, у которого `is_admin = FALSE`.

### Шаг 10. Точка запуска

```python
root = tk.Tk()
App(root)
root.mainloop()
```

- `tk.Tk()` создаёт главное окно;
- `App(root)` запускает приложение;
- `mainloop()` запускает цикл обработки событий окна.

Без `mainloop()` окно сразу закроется.

## 9. Частые ошибки

### `ModuleNotFoundError: No module named 'psycopg'`

Активируйте виртуальное окружение и установите пакет:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install "psycopg[binary]"
```

### Ошибка подключения к PostgreSQL

Проверьте:

- запущена ли служба PostgreSQL;
- пароль в строке `DB`;
- имя базы `demoekz`;
- порт `5432`;
- существует ли таблица `users`.

### `FileNotFoundError` для изображения

Проверьте, что папка `pictures` находится рядом с `main.py`, а файлы имеют имена `1.png`, `2.png`, `3.png`, `4.png`.

### Окно не открывается

Проверьте синтаксис:

```powershell
python -m py_compile main.py
```

Затем запустите приложение напрямую:

```powershell
python main.py
```

## 10. Что нужно улучшить в настоящем проекте

1. Не хранить пароль PostgreSQL прямо в исходном коде. Использовать переменные окружения.
2. Не хранить пароли пользователей в открытом виде. Использовать хеширование `bcrypt` или `argon2`.
3. Переименовать поле `password_hash` только после перехода на реальные хеши.
4. Разделить интерфейс, работу с базой и настройки по разным файлам.
5. Добавить автоматические тесты для авторизации и блокировки.
6. Добавить `.env` в `.gitignore` и не отправлять секреты в Git.
7. Для производственного приложения открывать одно соединение с базой через пул, а не создавать соединение на каждый запрос.
